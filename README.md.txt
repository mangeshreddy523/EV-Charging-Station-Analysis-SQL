# EV Charging Station Analysis Using MySQL

## Project Overview
This project analyses EV charging stations, users, and charging sessions using MySQL.

## Dataset
- Stations: 15 records
- Users: 35 records
- Charging Sessions: 250 records
- Total: 300 records

Note: This project uses synthetic data created for SQL practice.

## Tools Used
- MySQL Workbench
- SQL
- GitHub

## SQL Concepts
- SELECT, WHERE, ORDER BY
- GROUP BY, HAVING
- Aggregate Functions
- Joins
- Subqueries
- CTEs
- Window Functions
- Views
- Primary Keys and Foreign Keys

## Database Relationships
- Users to Charging Sessions: One-to-Many (1:N)
- Stations to Charging Sessions: One-to-Many (1:N)

## Project Objectives
- Analyse charging costs and energy consumption.
- Identify high-performing charging stations.
- Analyse EV user charging behaviour.
- Practise SQL queries and functions.
